GitHub 热门榜单 ​

查看 GitHub 仓库 →

自动抓取 GitHub 热门仓库信息，按 年/月/日 归档为 Markdown，支持本地定时任务与 GitHub Actions 每 6 小时更新。

Python1★MIT

特性 ​

  • 每日 Star TOP10、Fork TOP10、Trending TOP10
  • AI 方向热榜：Python · Deep Learning · Machine Learning
  • 数据文件 YYYYMMDD.md，同日复跑带时间戳 YYYYMMDD_HHMM.md 避免覆盖
  • 表格呈现：语言、Star、Fork、简介与仓库链接
  • Push 到 main 可触发 Actions 工作流

环境要求 ​

  • Python 3
  • 依赖见 requirements.txt

安装 ​

bash
git clone https://github.com/wangqiqi/github-trend.git
cd github-trend
pip install -r requirements.txt

快速开始 ​

单次抓取 ​

bash
python scraper.py

本地定时（每 6 小时） ​

bash
python scheduler.py

GitHub Actions ​

工作流 .github/workflows/update-trending.yml 默认在 UTC 0:00 / 6:00 / 12:00 / 18:00 运行，也支持 push 触发与手动 dispatch。

Fork 后一般 无需改 git 配置（使用 ${GITHUB_ACTOR}）；也可换成自己的 email/name。

数据存储 ​

data/
  └── 2026/
      ├── 01/
      │   ├── 20260101.md
      │   ├── 20260101_1200.md
      │   └── ...
      └── ...

辅助脚本：

脚本作用
merge_files.py合并同日多份抓取
cleanup.py清理冗余文件

自定义配置 ​

  1. scraper.py — 增删语言/主题抓取函数
  2. scheduler.py — 调整本地 cron 间隔
  3. update-trending.yml — 修改 Actions cron 表达式

常见问题 ​

Q: 没有 GitHub Token 能跑吗？
公开 Trending 页面抓取通常不需要 Token；Actions 提交需仓库 write 权限。

Q: 和 github-trending 官方 API 的关系？
本项目为 爬虫 + 归档 方案，输出静态 Markdown 便于阅读与 diff。
