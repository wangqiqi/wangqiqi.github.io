GitHub 热门榜单 ​

访问在线站点 →查看 GitHub 仓库 →

每天抓取 GitHub 热门仓库信息（Star TOP10 · Fork TOP10 · Trending TOP10 · Python TOP10），按 年/月/日 归档为 Markdown + JSON，并发布为带日历与全文搜索的在线站点。

Python2★MITVitePress

在线站点 ​

  • 站点地址：https://znza.top/github-trend/
  • 年度日历：https://znza.top/github-trend/calendar/2026 —— 一天一格，有快照的日期可点进当日榜单，缺口与未抓取日期如实标注
  • 趋势榜：https://znza.top/github-trend/trends/ —— 由全历史数据聚合的 Star 增速榜 / 常青榜 / 新晋榜

站点内容每次构建时从仓库 data/ 现场生成，data/ 是唯一源头；生成物不入库。

特性 ​

  • 每日四个榜单：Star TOP10、Fork TOP10、Trending TOP10、Python TOP10
  • 数据同时产出 Markdown（人看）与 JSON（程序用，Star/Fork 为整数）
  • 全量索引 data/index.json 与趋势产物 data/trends.json（纯函数，结果可复现）
  • 抓取带超时与退避重试；抓不全就整体失败、不落盘，不会提交半成品
  • 同日重复抓取自动避让文件名（秒级时间戳 / 序号），不覆盖既有数据

环境要求 ​

  • Python 3（本地抓取）
  • Node 20+（本地预览站点，可选）
  • 依赖见 requirements.txt

安装 ​

bash
git clone https://github.com/wangqiqi/github-trend.git
cd github-trend
pip install -r requirements.txt

快速开始 ​

单次抓取 ​

bash
python scraper.py

可选带 token 绕开 GitHub API 未认证限流：

bash
GITHUB_TOKEN=ghp_xxx python scraper.py

本地定时（每 6 小时） ​

bash
python scheduler.py

注意：每 6 小时是本地 scheduler 的频率；线上 GitHub Actions 是每天一次（见下）。

本地预览站点 ​

bash
npm install
npm run docs:dev

验收 ​

bash
pip install -r requirements-dev.txt
bash scripts/verify-all.sh   # Python 套件 + 站点构建与产物断言

GitHub Actions ​

三个工作流：

工作流作用
update-trending.yml每天 12:00 UTC 定时抓取并提交数据；支持手动触发。刻意不用 push 触发（同日快照不覆盖，代码推送会白攒多份文件）
ci.yml推送与 PR 时跑 Python 套件与站点构建断言
deploy-site.yml构建并部署站点到 GitHub Pages；除 push 外还监听抓取 workflow 的 workflow_run

Fork 后一般 无需改 git 配置（使用 ${GITHUB_ACTOR}）；也可换成自己的 email/name。

数据存储 ​

data/
  ├── index.json              # 全量索引（每天的文件清单）
  ├── trends.json             # 趋势产物（增速 / 常青 / 新晋）
  └── 2026/10/
      ├── 20261012.md         # 人看的表格
      └── 20261012.json       # 程序用的快照

辅助脚本（tools/ 下为维护脚本，默认 dry-run，--apply 才写盘并先备份）：

脚本作用
scripts/build_index.py重建 data/index.json
scripts/build_trends.py生成 data/trends.json
tools/merge_files.py合并 / 原地重排同日多份数据
tools/cleanup.py清理同日冗余文件

自定义配置 ​

  1. scraper.py — 增删语言/主题抓取函数
  2. scheduler.py — 调整本地定时间隔
  3. update-trending.yml — 修改 Actions cron 表达式

常见问题 ​

Q: 没有 GitHub Token 能跑吗？
公开 Trending 页面抓取通常不需要 Token，但 GitHub Search API 未认证限流较紧（10 次/分）；Actions 提交需仓库 write 权限。

Q: 和 github-trending 官方 API 的关系？
本项目为 爬虫 + 归档 + 站点 方案，输出 Markdown / JSON 双份，便于阅读、diff 与程序消费。

Q: 为什么有些日期没有数据？
历史上有两类：当年 GitHub API 失败（快照缺 Star/Fork 段落）与抓取整体失败（当天无快照）。日历与数据说明里如实标注，不做美化。
