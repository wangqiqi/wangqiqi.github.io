Cursor AI Rules ​

查看 GitHub 仓库 →

宪法驱动的 Cursor 协作配置模板 — 将 .cursor/、AGENTS.md、.cursorignore 复制到任意项目即可使用；或安装为 Cursor 本地插件。侧重 规则体系、技能库、/master 中枢与 VIBE 对话式开发。

与本博客母版 Super Cursor 的关系：Super Cursor 由 cursor-ai-rules 演进而来，保留三公理与双目录思想，并强化 plan/run 闸门、runner.sh 验收与 7 栈脚手架。

Cursor v0.40+15★77 rules · 46 skills

特性 ​

  • 三大公理：意图主权 · 信号可信 · 认知可审计
  • 三大无关：项目无关 · 系统无关 · 用户无关（数据进 .cursorGrowth/）
  • 77 条 .mdc 规则 + 75+ Shell 脚本 + 46 Agent Skills
  • 21 种人格角色（能力等价，仅对话风格不同）
  • 团队经验沉淀：team-experience 技能，教训写入 Growth 不污染主规则树
  • Token 优化：.cursorignore 缩小 @codebase 索引

环境要求 ​

项要求
Cursorv0.40+
Git2.0+（可选）
Bash4.0+
jq可选，部分 Master 脚本推荐

安装 ​

方式 A — 复制到项目（推荐，完整 hooks + core） ​

bash
git clone https://github.com/wangqiqi/cursor-ai-rules.git
DEST=/path/to/your-project

cp -r cursor-ai-rules/.cursor "$DEST/"
cp    cursor-ai-rules/AGENTS.md "$DEST/"
cp    cursor-ai-rules/.cursorignore "$DEST/"

cd "$DEST" && bash .cursor/core/init.sh --quickstart   # 可选

方式 B — Cursor 插件（全局） ​

bash
git clone https://github.com/wangqiqi/cursor-ai-rules.git
cd cursor-ai-rules
mkdir -p ~/.cursor/plugins/local
ln -sfn "$(pwd)" ~/.cursor/plugins/local/cursor-ai-rules
# 重启 Cursor

勿复制到业务仓库 ​

.cursorGrowth/、.cursor-plugin/、.github/、scripts/、仓库根 docs/ — 均为维护者或本地生成路径。

.cursorignore ​

缩小索引体积；不移除 alwaysApply: true 的宪法规则。业务项目若已有 .cursorignore，请合并而非覆盖。

常见问题 ​

Q: 是 Cursor 官方产品吗？
否，是开源配置模板；Agent 行为由用户在本机 Cursor 会话中触发。

Q: 并行 Agent 会远程代跑代码吗？
否，max_parallel_executions 等仅描述本地可选工作流。

Q: 和 Trae AI 的区别？
Trae AI 面向 Trae IDE；本仓库面向 Cursor 的 rules/skills/hooks 协议。
