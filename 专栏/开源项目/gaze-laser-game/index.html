Eye Laser Game ​

查看 GitHub 仓库 →

基于 眼动追踪 的激光射击小游戏：摄像头实时检测双眼位置，持续发射激光；摸鼻子 触发强力激光。目标从四面八方飞来，含普通靶与炸弹靶、关卡与生命系统。

Python 3.7+MediaPipeOpenCV · PygameMIT

效果展示 ​

玩法 ​

  • 双眼位置持续发射 普通激光，消灭飞来的目标
  • 触摸鼻子 发射强力激光，适合清场或打炸弹靶
  • 区分普通靶与炸弹靶；炸弹误击会扣生命
  • 关卡递进、生命有限；带音效与粒子特效

环境要求 ​

  • Python 3.7+
  • 可用 摄像头（笔记本内置或 USB）
  • 依赖：OpenCV、MediaPipe、Pygame、NumPy（见 requirements.txt）

安装与运行 ​

bash
git clone https://github.com/nxu-game/gaze_laser_game.git
cd gaze_laser_game
pip install -r requirements.txt

启动（二选一）：

bash
python run.py
# 或
python -m gaze_laser_game

音效与资源（可选） ​

音效文件可放入 gaze_laser_game/assets/sounds/：

文件说明
laser.wav普通激光
bomb0.mp3普通靶爆炸
bomb1.mp3炸弹爆炸
game_over.mp3游戏结束

缺失时使用程序内默认或静音，不影响核心玩法。

常见问题 ​

Q: 激光偏移或不准？
保证光线充足、面部完整入镜；可调整摄像头分辨率与 MediaPipe 检测置信度（见仓库 Issues）。

Q: 与 nxu-tech 安监项目有何不同？
本栏目侧重 趣味互动与本地跑通；nxu-tech 为生产级 CV SDK，见 CV安监项目集合。
