OpenCV Python 教程 ​

查看 GitHub 仓库 →

OpenCV-Python 系统教程 的代码与 Notebook 仓库，与 CSDN 系列文章《【OpenCV-Python】教程》一一对应，覆盖 GUI 到机器学习、目标检测共 10 章。

Jupyter Notebook2★OpenCV-Python

效果展示 ​

特性 ​

  • 按官方 OpenCV 教程结构组织的 中文笔记 + 可运行示例
  • 章节从图像读写、视频、GUI 交互到 特征检测、视频分析、相机标定、ML
  • 同步维护 Gitee 镜像 便于国内访问
  • 与 CV安监 算法栈衔接：适合 CV 入门再读 nxu-tech SDK

环境要求 ​

  • Python 3
  • opencv-python（及章节所需的 numpy、matplotlib 等）
  • Jupyter Lab / Notebook（推荐）

安装 ​

bash
git clone https://github.com/wangqiqi/opencv-python-tutorial.git
cd opencv-python-tutorial
pip install opencv-python numpy matplotlib jupyter
jupyter lab

在仓库内打开对应章节的 .ipynb 或 .py 示例即可。

章节大纲 ​

章主题内容摘要
1GUI Features图像/视频读写、画图、鼠标事件、TrackBar
2Core Operations基础操作、算术运算、性能测量
3图像处理色彩空间、几何变换、阈值、滤波、形态学、边缘、轮廓、直方图、模板匹配、Hough、分割
4特征检测Harris、Shi-Tomasi、SIFT/SURF/FAST、BRIEF、ORB、特征匹配
5视频分析背景减除、Meanshift/Camshift、光流
6相机标定标定、姿态估计、对极几何、立体深度
7机器学习kNN、KMeans、SVM、PCA
8计算图形去噪、修复、HDR
9目标检测Haar 级联分类器与训练
10Python BindingsOpenCV Python 绑定原理

配套文章 ​

完整图文讲解在 CSDN 黄金旺铺 专栏，仓库 readme.md 含每节直达链接。入门推荐顺序：

  1. 1-1 图像读取显示保存
  2. 3-7 Canny 边缘检测
  3. 4-8 ORB 特征

快速开始（示例） ​

python
import cv2

img = cv2.imread("samples/lena.jpg")
cv2.imshow("demo", img)
cv2.waitKey(0)
cv2.destroyAllWindows()

具体路径以仓库内 samples/ 与实际 Notebook 为准。

常见问题 ​

Q: 仓库主要是链接还是代码？
两者都有：readme 链到 CSDN 文章，目录内为可运行的 Notebook/脚本示例。

Q: SIFT/SURF 在新版 OpenCV 中不可用？
部分算法需 opencv-contrib-python 或特定版本；以各 Notebook 头部说明为准。

Q: 与 nxu-tech 的关系？
本教程偏 OpenCV 基础；生产级检测部署见 nxu-tech YOLOv8 SDK。
