视频质量诊断 · 技术专题 ​

面向安防监控、流媒体运维、视频平台质检等场景，本专题系统介绍如何用传统计算机视觉方法自动发现画面异常——原理可解释、公式可推导、无需深度学习模型。

本专题为算法科普，不涉及具体 SDK / 工程实现；深度学习路线将在后续独立专题中展开。

你能学到什么 ​

维度内容
异常类型模糊、噪声、偏色、过亮/过暗、低对比度、蓝屏、马赛克、花屏、遮挡、抖动、冻结
方法体系单帧图像处理 + 时序分析（光流、帧差）
交付形态每篇含公式（MathJax）、流程图（Mermaid）与示意图

技术路线概览 ​

flowchart TB
    A[输入视频帧] --> B[预处理]
    B --> C[单帧检测]
    B --> D[时序检测]
    C --> C1[清晰度 / 噪声]
    C --> C2[色彩 / 亮度 / 对比度]
    C --> C3[蓝屏 / 块效应 / 遮挡]
    D --> D1[光流 → 抖动]
    D --> D2[帧差 → 冻结]
    C1 --> E[阈值判定]
    C2 --> E
    C3 --> E
    D1 --> E
    D2 --> E
    E --> F[异常报告]

阅读建议 ​

  1. 先读 01 · 总览，建立异常分类与判定框架。
  2. 按业务关注点选读单帧或时序章节；各篇相互独立，可跳读。
  3. 公式默认用 $...$（行内）与 $$...$$（块级）排版，需站点 MathJax 支持（已启用）。
  4. 插图见 来源清单：本地样例已脱敏（去除 OSD / 地理位置 / 水印）；08 章等部分使用 Wikimedia 公开图。

应用场景 ​

  • 安防监控：摄像头失焦、遮挡、冻结、抖动告警
  • 流媒体运维：码率不足导致的马赛克、花屏检测
  • 视频平台：上传内容质量预审
