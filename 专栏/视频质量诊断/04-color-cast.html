04 · 偏色检测 ​

偏色（Color Cast） 指画面整体色调偏移——偏黄、偏绿、偏蓝等，通常由白平衡错误、光源色温变化或 ISP 参数不当引起。

1. 为什么用 Lab 颜色空间 ​

CIE L*a*b* 将亮度（）与色度（）分离：

通道含义
亮度，0（黑）～100（白）
绿 ← → 红
蓝 ← → 黄

正常中性灰应满足 。偏色时色度向量整体偏移。

整体色调偏移（已脱敏：去除 OSD 水印）

  • 大 → 整体色调偏移明显
  • 小 → 颜色种类少（单色偏）
  • 越大 → 偏色越显著

3. 几何解释 ​

在 平面上，像素云中心距原点越远， 越大；云团越集中， 越小， 升高。

flowchart LR
    A[BGR 图像] --> B[cvtColor → Lab]
    B --> C[提取 a*, b* 平面]
    C --> D[计算 D, M]
    D --> E[K = D / M]
    E --> F{K > T?}
    F -->|是| G[偏色告警]

4. 实现要点 ​

cpp
Mat lab;
cvtColor(bgr, lab, COLOR_BGR2Lab);
// 分离 a*, b* 通道（OpenCV Lab 为 8-bit 编码，需按标准转换）
Scalar meanA, stdA, meanB, stdB;
// ... meanStdDev 得 bar_a, bar_b, sigma_a, sigma_b
double D = sqrt(bar_a*bar_a + bar_b*bar_b);
double M = sqrt(sigma_a*sigma_a + sigma_b*sigma_b);
double K = D / (M + 1e-6);

OpenCV 的 Lab 为 编码，应用时需按 CIE 规范反量化到物理 ，或在整个流程中保持一致标定。
